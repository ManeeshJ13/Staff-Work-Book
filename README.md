# DVJ & Associates Assignment Management System 

A web based assignment management system designed for DVJ & Associates to track, assign and monitor client-related tasks efficiently, reducing manual follow-ups and improving work flow
It has 2 distinct roles:
- **Staff**
- **Admin**

## Features

### Staff Module
- Enter daily work details for assigned tasks
- Select client, type of work, and working time
- Mark daily attendance
- View previously submitted work entries and edit them

### Admin Module
- View Daily Attendance Summary
- View Daily Work Summary
- Generate time and cost reports
- add, edit or remove:
  - Clients
  - Staff
  - Assignments
- Verify Staff Attendance Entries

## Tech Stack
- Frontend : **React**
- Backend & Database : **Supabase**
- Authentication: Supabasse Auth
- Hosting : Vercel
